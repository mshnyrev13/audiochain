# AudioChain

Нативный визуальный конструктор аудиоцепочек для **macOS 14.2+ / Apple Silicon**.

Источник → AU-плагины → выбранный аудиоинтерфейс. Блоки соединяются вручную; поддерживаются последовательные и параллельные ветки с общим выходом.

[Скачать последнюю версию](https://github.com/mshnyrev13/audiochain/releases/latest)

## Возможности

- Источник: звук системы, отдельное приложение, аудиовход или файл.
- Core Audio Process Tap отключает прямое воспроизведение перехваченного приложения на время работы цепочки; Стоп возвращает обычный звук.
- Библиотека AU со сканированием стандартных папок Components, поиском и избранным. Генераторы создают звук без аудиовхода.
- Собственные редакторы AU: двойной клик по карточке или шестерёнка. Кнопка питания включает host bypass.
- Компактные блоки, свободное расположение, масштаб, поиск и мини-карта. Длина цепочки не ограничена переносом на следующую строку.
- Отмена/повтор структурных действий, сохранение JSON и автоматическое открытие последнего конфига.
- Уровни L/R в dBFS, оценки задержек входа/выхода, диагностика сигнала, счётчики подрывов, CPU/RAM и измерения render каждого AU.
- Итоги нагрузки сохраняются после Стоп; панель сортирует AU по аудиобюджету и показывает стабильные номера экземпляров. Проверка новых стабильных релизов GitHub раз в сутки; предложение обновиться откладывается до остановки звука.

## Установка

1. Скачайте DMG из [GitHub Releases](https://github.com/mshnyrev13/audiochain/releases/latest).
2. Закройте предыдущую версию AudioChain и перетащите приложение в «Программы».
3. Откройте настройки источника и выхода двойным кликом, добавьте AU и соедините порты.
4. Нажмите Старт. Для изменения структуры или аудиоустройства сначала нажмите Стоп.

Сборка подписана локальной ad-hoc подписью; Apple Developer ID и notarization пока не используются. Установленные сторонние AU и их лицензии в поставку не входят.

## Обновления

В меню AudioChain есть «Проверить обновления…» и переключатель автоматической проверки. Автоматические запросы выполняются не чаще одного раза в сутки; ручная проверка доступна в любой момент. GitHub получает обычный запрос к публичному API без токенов, cookies, конфигов цепочки или сведений об установленных плагинах.

Приложение сравнивает числовую версию с последним стабильным релизом и проверяет наличие DMG. Черновики, prerelease и более старые версии не предлагаются. Можно открыть страницу релиза, отложить предложение или пропустить версию. Пока аудиотракт работает или готовится, окно не открывается. Загрузка и установка выполняются пользователем со страницы релиза; приложение не перезаписывает себя во время воспроизведения.

Проверка обновлений появилась в **0.1.34**: более раннюю версию нужно обновить вручную один раз.

## Управление

| Действие | Клавиши |
| --- | --- |
| Старт / Стоп | ⌘Return |
| Открыть / сохранить схему | ⌘O / ⌘S |
| Отменить / повторить | ⌘Z / ⇧⌘Z |
| Найти блок | ⌘F; ↑↓ выбор, Enter переход, Esc закрытие |
| Библиотека AU / диагностика | ⌘B / ⌘D |
| Удалить выбранный провод / отменить соединение | Delete / Esc |

## Звук и ограничения

- Без активных AU, при 100% и совместимом прямом маршруте Float32 PCM сохраняется побитово. Для process/system источника прямой выход должен совпадать с выходом источника; для аппаратного входа требуется тот же интерфейс. Несовместимый прямой маршрут отклоняется. Изменение уровня меняет PCM.
- AU-путь использует Mastering SRC и синхронизацию независимых аудиочасов. Параллельные входы суммируются при unity; автоматической компенсации задержек веток нет.
- Метры показывают sample peak, не true peak/RMS/LUFS. Задержки оцениваются по очереди, HAL и заявленным значениям AU; это не аппаратный loopback.
- Нагрузка AU — wall time render за вычетом измеренных вложенных AU, а не точное CPU каждого плагина. RAM относится ко всему приложению.
- Наличие AU в каталоге не гарантирует совместимость. AUv2 работает в процессе хоста, поэтому сбой стороннего плагина может завершить приложение.
- Нужны соответствующие разрешения macOS для микрофона и системного аудио. Защищённый контент может быть недоступен. MIDI-вход, выбор физических L/R-каналов и parallel PDC пока не реализованы.

## Сборка

Нужны Apple Command Line Tools с Swift, macOS и Apple Silicon. Сторонних зависимостей нет.

```sh
zsh build.sh build-release
zsh scripts/make-dmg.sh build-release
```

Диагностическая сборка:

```sh
zsh build.sh build-tests --diagnostics
build-tests/AudioChain.app/Contents/MacOS/AudioChain --self-test
build-tests/AudioChain.app/Contents/MacOS/AudioChain --update-tests
```

Часть диагностик требует установленных AU, собственного конфига, разрешений macOS или виртуального ZoomAudioDevice. Аппаратные и vendor-сценарии запускайте только в подготовленном окружении. Диагностики не включаются в обычный release.

## Публикация следующего релиза

1. Измените `CFBundleShortVersionString` и увеличьте `CFBundleVersion` в `Resources/Info.plist`.
2. Соберите и проверьте приложение и DMG.
3. Выполните `python3 scripts/prepare-github-release.py build-release/AudioChain-VERSION.dmg`.
4. Закоммитьте код и обновлённую папку `Distribution` в `main`.

Workflow сверит версию и SHA256, загрузит DMG и SHA256SUMS в черновик GitHub Release и опубликует его после загрузки файлов. Уже опубликованная версия не перезаписывается. Клиенты предлагают обновление только после публикации готового релиза.
